## 1. Purpose and conventions

This register records every material contradiction found while inventorying SpeakCraft's 59 documentation artefacts (see RD-01, `01_DOCUMENT_INVENTORY.md`). Each contradiction is either between two documents, between a document and the code at HEAD (`68a9cb1`, 2026-11-20), or within a single document. The register proposes which source should be treated as authoritative. It does **not** resolve product decisions; those need product owner sign-off.

- **Document IDs** (`DOC-nnn`) follow RD-01. Paths are relative to the repository root.
- **Code references** use `path:line` at HEAD. All code evidence comes from static reading (`grep`/`read`/`git show`). **No code was built or run.**
- **Nature:** `doc-vs-doc` (two documents disagree), `doc-vs-code` (a document disagrees with the code), `doc-vs-self` (a document contradicts itself), `outdated` (the document was true when written but the code has since changed). Combinations are listed where more than one applies.
- **Severity:**
  - **High:** affects product direction, privacy, security or the credibility of verification claims, or would mislead an implementer on a core capability.
  - **Medium:** affects the scope, data model or planning of a feature.
  - **Low:** cosmetic, numeric or of local impact only.
- **Status:** every item is **Open** until the product owner approves a resolution.
